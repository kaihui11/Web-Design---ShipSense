# ShipSense — Ocean Logistics Cost Forecasting System

An ML-powered internal tool for logistics teams. Forecasts ocean freight shipping fees 90 days ahead, identifies the cheapest nearby booking window, and generates client quotations.

**Live:** https://web-design-ship-sense.vercel.app — deployed from `main` on every push (see [docs/deployment.md](docs/deployment.md)).

---

## Quick Start

```bash
cd frontend
python -m http.server 8080
# open http://localhost:8080
```

`http://localhost:8080` opens the **login screen**. Everything else in the system is behind it — there is no public half of the site.

Login/signup requires a real `@goodfortune.com` account backed by Supabase Auth — sign up from the login page if you don't have one yet (see `supabase/README.md` for enabling email auth on the project).

## What It Does

One page, one menu. Signing in lands on Home; the sidebar reaches all nine pages and stays identical on every one of them.

**Overview**

1. **Home** — what the system is, the accuracy figures, the three-step workflow and the lane it covers
2. **About** — the company, what is actually under the forecast, and what it explicitly does not claim

**Forecasting**

3. **New Forecast** — the data-entry form: route, Intended Ship Date, container count, company and person in charge
4. **Forecast Result** — ML-predicted daily rates for ±5 days around your date, with the cheapest highlighted
5. **Client Quote Preview** — generate a quotation with 20% markup and a 48-hour validity window

**Records & insight**

6. **Forecast History** — the records table: browse, filter, edit and delete past forecasts and quotations
7. **Executive Dashboard** — Forecast tab (ISD-driven KPIs, trend chart, a calendar aligned to real weekdays, daily table, macro slicer) and Historical Data tab (trend chart + table with clear/month/year granularity)
8. **Market Impact** — an exchange-rate slider against the 90-day forecast. Explicitly an illustration, not a model output: the pipeline produces one central path and cannot answer "the fee at a different exchange rate" (see [docs/frontend-user-flow.md](docs/frontend-user-flow.md#page-8--market-impact)), so quotes are never priced from it

**Support**

9. **Contact / Help** — five answers to the questions the workspace raises most often, the freight desk's details, and an enquiry form validated in JavaScript and stored in Supabase's `contact_messages` table

## Project Overview

| Property | Value |
|---|---|
| Route | North Europe → US East Coast (Rotterdam → New York) |
| Forecast target | Daily ocean freight rate, USD per 40ft container (FEU) |
| Forecast horizon | 90 days |
| Model | XGBoost regression (time-series, rolling features) |
| Risk analysis | External shock scoring + Vine Copula dependency |
| Frontend | Single-page app behind a login — nine views. HTML, CSS, vanilla JS |
| Data source | Xeneta XSI-C index (XSICNEUE lane) |

## Data Pipeline

ML notebook exports a `ShipSenseWebsiteBundle` (`shipsense_website_bundle.pkl`) → push triggers `.github/workflows/update-forecast-pkl.yml`, which runs `scripts/pkl_to_json.py` → POSTs the forecast into Supabase's `snapshots` table (JSONB, `kind='forecast'`) and the historical actuals into `historical_data` (one row per day) via its REST API → frontend reads both tables directly over PostgREST, no custom server involved. See [supabase/README.md](supabase/README.md) and [docs/data-pipeline.md](docs/data-pipeline.md).

- **Executive Dashboard → Forecast tab** (chart, table, calendar) sources **strictly from Supabase's `snapshots` table** — if Supabase isn't configured or has no forecast snapshot yet, the tab simply shows no data.
- **Executive Dashboard → Historical Data tab** sources **strictly from Supabase's `historical_data` table** — same rule.
- The Shipping Fee Calendar places each forecast row on its true calendar weekday (leaving weekends blank) rather than packing rows 7-per-row in sequence, since the forecast only contains business days.
